進行中生成AI・業務自動化

AI業務改善・自動化プロジェクト（FDE）

生成AIおよび業務自動化技術を活用し、社内業務の効率化を目的としたPoC・システム化を推進。残業代計算、実績データ集計、銀行取引データの自動仕訳などのテーマに取り組んでいます。

期間
2026年10月～現在
役割
プロジェクトリーダー
体制
8名（リーダー1＋メンバー7）
  • Python
  • Azure OpenAI Service
  • Microsoft Copilot
  • Claude
約16時間
実績Excelデータの自動集計で削減した月初の作業時間

課題

月初の集計作業が手作業で、他の締め切りと重なり業務負荷と入力ミスが発生していました。また開発メンバーに業務知識がなく、手戻りのリスクがありました。

取り組み

  • 計画策定・スケジュール管理・課題管理などプロジェクト全体を統括
  • メンバー7名のタスク割り振り・進捗管理・育成
  • 現場部門へのヒアリングで業務課題を整理し、AI活用テーマを選定・優先順位付け
  • 業務フロー・業務ルールを開発メンバー向けガイドラインとして整理・説明
  • 実績データ自動集計の要件定義・検証・導入、銀行取引自動仕訳のPoCを推進
  • 会議ファシリテーション・合意形成・進捗報告

成果

  • 月初の集計作業時間を約16時間削減
  • 手入力をなくし入力ミスを削減、期限内の業務完了に貢献
  • ガイドライン提示により手戻りを抑えて開発を推進
  • 利用部門から「ストレスがかなり減った」「とても助かっている」と高評価
Web・CMSリーダー

製薬企業向けWebサイト CMS移行

大手製薬企業の既存Webサイト7件および新規サイトを新CMSへ移行。ホームページ・LP・ウェビナー・製品ページなどの新規構築も担当しました。

期間
2021年10月～2023年10月
役割
リーダー
体制
3名
  • 独自CMS
  • HTML
  • CSS
  • Google Analytics
  • Photoshop
  • JIRA
  • Confluence

課題

新CMSのドキュメントが少ないなか、既存サイトのデザイン・UXを維持したまま移行する必要があり、日本とグローバルの関係者間での認識合わせも求められていました。

取り組み

  • 移行対象コンテンツの調査・棚卸しと移行方針の整理
  • 新CMSの仕様調査・挙動確認と移行要件の調整
  • 移行スケジュールの策定とタスク・メンバー管理
  • 新CMSでのページ制作・更新・公開
  • UI・デザイン整合性の確認と多デバイス検証
  • グローバルチームとの英語による仕様調整

成果

  • 既存7サイト＋新規サイトの移行をスケジュール通り完遂
  • 新CMSの仕様を早期に習得し、手順をチーム全体へ展開
  • 日英間の仕様調整を主導し、認識齟齬による手戻りを防止

建材検査管理システム

建材検査業務を一元管理する業務システムの品質検証。2026年4月以降は顧客窓口として、操作説明・導入支援・追加要望の整理を担当しています。

期間
2025年5月～12月（QA）・2026年4月～現在
役割
QA／顧客窓口
体制
12名
  • Delphi
  • GeneXus
  • PostgreSQL

課題

実際の検査業務に沿って確実に動作することが求められ、導入後は顧客への手厚いサポートと要望の受け皿が必要でした。

取り組み

  • 業務フローを踏まえたテスト設計・実施
  • 不具合の再現確認・検証と開発チームへの報告
  • 顧客先での操作説明・導入支援
  • 追加・改善要望のヒアリング・整理と開発メンバーへの共有・フォロー
  • 顧客からの問い合わせ対応

成果

  • 不具合の早期検出によりシステム品質向上に貢献
  • テスト観点の整理によりテスト品質を均一化
  • 要望を正確に伝達し、円滑な追加対応に貢献
